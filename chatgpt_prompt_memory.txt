What the app currently does
- Users have roles: admin, teacher, student.
- Users also have section, teacher_token, approval_status, approved_at, approved_by, and soft deletes.
- User dashboard routing is role-based:
  - admin -> admin.dashboard
  - teacher -> teacher.dashboard
  - student/default -> student.dashboard
- Admin features include dashboard, token request approval/decline, user edit/update/delete, trash, restore, force delete, and empty trash.
- Teacher features include dashboard, student roster/detail pages, reports, and assessment creation/viewing.
- Student features include dashboard, activities, published assessment view, and rewards.
- Assessments belong to a teacher through created_by and include title, subject, quiz_type, delivery_method, target_section, focus_areas, asset_path, manual_questions, instructions, and status.
